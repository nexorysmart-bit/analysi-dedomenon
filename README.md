# 📊 Στούντιο Ανάλυσης Δεδομένων · Data Analysis Studio

🔗 **Live demo:** https://nexorysmart-bit.github.io/analysi-dedomenon/

Δίγλωσση εφαρμογή ανάλυσης δεδομένων (Ελληνικά / English) που τρέχει εξ ολοκλήρου στον browser, χωρίς εγκατάσταση. Ανοίγεις ένα αρχείο CSV ή Excel και παίρνεις έλεγχο ποιότητας, καθαρισμό, ερωτήματα SQL, ανάλυση, αυτόματα συμπεράσματα και επαγγελματική αναφορά.

A bilingual (Greek / English) data analysis app that runs entirely in the browser with no installation. Open a CSV or Excel file and get quality checks, cleaning, SQL queries, analysis, automatic insights and a professional report.

## ✨ Λειτουργίες / Features

| | Ελληνικά | English |
|---|---|---|
| 🔎 | Επισκόπηση: γραμμές, στήλες, κενά, διπλότυπα, βαθμός ποιότητας | Overview: rows, columns, missing values, duplicates, quality score |
| 🧹 | Καθαρισμός με ένα κλικ, με καταγραφή κάθε αλλαγής | One-click cleaning with a log of every change |
| 🗄️ | Εργαστήριο SQL σε πραγματική SQLite (GROUP BY, CTE, window functions) | SQL Lab on real SQLite (GROUP BY, CTEs, window functions) |
| 📈 | Ανάλυση ανά κατηγορία, τάσεις στον χρόνο, ακραίες τιμές (IQR), συσχετίσεις | Group analysis, time trends, outliers (IQR), correlations |
| 🐍 | Κώδικας Python / pandas πάνω στα δεδομένα | Python / pandas code on your data |
| 💡 | Αυτόματα συμπεράσματα σε απλή γλώσσα | Automatic plain-language insights |
| 📄 | Αναφορά HTML έτοιμη για αποστολή | Ready-to-share HTML report |

Υποστηρίζει ελληνικές μορφές αρχείων: διαχωριστικό `;`, υποδιαστολή `,`, ημερομηνίες ηη/μμ/εεεε.

## 🔒 Ιδιωτικότητα / Privacy

Τα δεδομένα δεν ανεβαίνουν πουθενά. Όλη η επεξεργασία γίνεται στη συσκευή του χρήστη.
Data is never uploaded; all processing happens on the user's device.

JavaScript · SQL (SQLite via sql.js) · Python (pandas via Pyodide) · HTML/CSS · GitHub Pages

Δημιουργήθηκε με AI-assisted development (vibe coding) και δοκιμάστηκε σε κινητό και υπολογιστή.
Built with AI-assisted development (vibe coding) and tested on mobile and desktop.
